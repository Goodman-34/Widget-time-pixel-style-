# Dukungan

Butuh bantuan dengan Pixel Drive Clock? Urutan tercepat:

## 1. Baca bagian pemecahan masalah

Masalah paling umum sudah dibahas di
[README → Pemecahan masalah](README.md#-pemecahan-masalah):

- Widget tidak muncul setelah dijalankan
- Tampilan aneh, berkedip, atau layar hitam
- Pixel terlihat kurang rata (penskalaan 125%/175%)
- "Jalan otomatis" tidak bekerja setelah `.exe` portable dipindah
- `npm run build` gagal *out of memory*
- `npm start` tidak memunculkan apa-apa

## 2. Cari di issue yang sudah ada

Mungkin sudah pernah ditanyakan:
[daftar issue](https://github.com/Goodman-34/Widget-time-pixel-style-/issues?q=is%3Aissue).

## 3. Buka issue baru

Kalau belum ada jawabannya, buka
[issue baru](https://github.com/Goodman-34/Widget-time-pixel-style-/issues/new/choose)
dan sertakan:

- Versi widget (mis. 1.0.0) dan jenisnya (installer / portable / dari sumber)
- Versi Windows (mis. Windows 11 23H2)
- Langkah-langkah sampai masalahnya muncul
- Tangkapan layar bila menyangkut tampilan

Untuk **celah keamanan**, jangan pakai issue publik — ikuti
[`SECURITY.md`](SECURITY.md).

Proyek ini dipelihara sukarela, jadi jawaban mungkin tidak instan. Terima
kasih atas kesabarannya.
